# Hi, I'm Khalil Moughamir

Third-year Computer Science student (**Data track**) at the IUT of Reims, currently on a dual-degree year at the **Université du Québec à Chicoutimi** (Canada).

I apply **data analysis to sport**. After more than **10 years at Stade de Reims**, from the football school to the training center, I build tools that turn performance data into decisions.

Founder of **KORA** (Key Operational Reporting for Athletes), a web platform that centralizes performance analysis for a professional football club's training center. It has been in production since August 2026 (private repository).

**Looking for:** a data / AI internship starting January 2027, then a work-study placement from September 2027.

## Featured Projects

### KORA (private)

Sports performance analytics platform, in production since August 2026: 6 viewing modules, 6 data-entry modules, 7 roles with per-team access, 27 users, 3 categories, 80 players.
Python, FastAPI, PostgreSQL, SQLAlchemy, Alembic, Pandas, React, Tailwind CSS, Recharts, Docker. The source code is private; details are on my [portfolio](https://khalil-moughamir.vercel.app).

### Olympic Games Paris 2024 Data Analysis

Querying and modifying an Olympic database in SQL, with interactive **Power BI** dashboards.

### Impact of Weather on Running Performance

Team project of 4: study of the impact of weather (Open-Meteo) on 2 x 400 m runs, with a shared sensor and an automated data pipeline. Built with **Python** and **Streamlit**.

### Football Data Analysis

Reports built with **Tableau**:
- **Playing style analysis**: Brentford (Premier League), tactical and statistical analysis.
- **Team performance analysis**: Stade de Reims (Ligue 2), collective performance.
- **Player replacement analysis**: data-driven profile of a replacement player for the transfer window.
